阶段顺序：M0差距/矩阵（完成）；M1来源结构；M2Dataset与Release；M3Identity/发号Ledger；M4扫描/写回/异常/对账；M5中文管理台与全P0验收；M6性能抽样/恢复与交付。完成各模块即执行其相关测试，失败修复复验。

默认决策：ERP SoR；拒绝直接DB回写；Root一行一物料；Identity默认一对一冲突；既有非空号默认不覆盖；已发规格变更仅异常；配置双人审批、逐条发号不人工审批；参考变化采用尚未发号Root定期重扫。先单位/类型/派生/校验再Identity（按PRD7.4执行顺序），最后Code与Ledger。解析须显式指定版本，多版本列表亦须显式指定，匹配多条返回PARSE_AMBIGUOUS。

独立ERP模拟源只用于开发验收，不是IFS/KRS迁移或真实ERP UAT。正式各类别完整拼接规则未提供，示例规则明确配置并断言预期值，不能宣称符合企业正式料号公式。生产容量/SLA、真实ERP认证与UAT需后续环境，不阻止本地P0开发。
